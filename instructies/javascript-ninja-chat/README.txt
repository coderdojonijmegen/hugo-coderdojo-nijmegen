# ninja-chat
Dit archief bevat de instructies en start code voor het maken van een simple Javascript gebaseerde chat applicatie.

De pagina's zijn zichtbaar via [https://coderdojonijmegen.github.io/ninja-chat/](https://coderdojonijmegen.github.io/ninja-chat/).

Gebruik Node.js 26 en npm om de chatserver vanuit deze map te starten:

    npm ci
    npm start

Open daarna http://localhost:3000/. De server kan ook zelfstandig vanuit `src/server` worden gebouwd en gestart; zie de README in die map.
