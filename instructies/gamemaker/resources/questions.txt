::text::
<img begin/scratch_vs_gameamaker.png 150 Scratch vs GameMaker>
GameMaker lijkt een beetje op Scratch, je kan er 2D-games mee maken.

Dat gaan we vandaag doen, maar er zijn een paar belangrijke verschillen tussen GameMaker en Scratch.

GameMaker is een stuk sneller, dus je kan er grotere games mee maken.
In GameMaker kun je ook meer dingen zelf programmeren met code. 
Wat in GameMaker met een paar regels code kan, kost in Scratch soms honderden blokjes.
Geen zorgen: in GameMaker gaan we ook gewoon blokjes gebruiken, al werken die een beetje anders dan in Scratch.
Met GameMaker kun je ook makkelijker je games delen, 
zo mag je vandaag je game uploaden naar onze website, zodat de andere kinderen de game kunnen spelen.
Het grootste verschil is dat je in GameMaker gemakkelijker (grote) levels kan maken.

In het algemeen is GameMaker een stuk professioneler.

::question:: Wat is een voordeel van GameMaker ten opzichte van Scratch?
::wrong:: GameMaker is een stuk ingewikkelder.
