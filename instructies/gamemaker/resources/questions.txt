::text::
<img begin/scratch_vs_gameamaker.png 150 Scratch vs GameMaker>
GameMaker lijkt een beetje op Scratch, je kan er 2D-games mee maken.

Dat gaan we vandaag doen, maar er zijn een paar belangrijke verschillen tussen GameMaker en Scratch.

GameMaker is een stuk sneller, dus je kan er grotere games mee maken.
In GameMaker kun je ook meer dingen zelf programmeren met code. 
Wat in GameMaker met een paar regels code kan, kost in Scratch soms honderden blokjes.
Geen zorgen: in GameMaker gaan we ook gewoon blokjes gebruiken, al werken die een beetje anders dan in Scratch.
Met GameMaker kun je ook makkelijker je games delen, 
zo mag je vandaag je game uploaden naar onze website, zodat de andere kinderen de game kunnen spelen.
Het grootste verschil is dat je in GameMaker gemakkelijker (grote) levels kan maken.

In het algemeen is GameMaker een stuk professioneler.

::question:: Wat is een voordeel van GameMaker ten opzichte van Scratch?

::section:: Vijanden
::text::
In dit hoofdstuk gaan we vijanden toevoegen die de room opnieuw start als je ze aanraakt. We gaan hem ook zelf laten bewegen.
::check::
::text::
Je hebt gekozen om een vijand aan het spel toe te voegen.
Als eerste maken we een sprite voor de vijand en voegen we die toe aan een object.
(Als je niet meer weet hoe je een sprite maakt, kijk dan bij "Speler maken", stap 4.)

Zet daarna het object van de vijand in de room, op dezelfde manier als bij de speler
(zie "Speler maken", vraag 6).

::question:: Heb je een enge vijand getekend?
::wrong:: Nee, het lukt niet.
::wrong:: Hij ziet er wel leuk uit.
::correct:: Ik heb de engste vijand ooit getekend!

::text::
Als de speler de vijand aanraakt, heeft de speler verloren.
Het level moet dan opnieuw beginnen.
Dit doen we door een "Collision"-event (Engels voor botsing) toe te voegen aan het object van de vijand.
<img vijanden/collsion_event_speler.png 500 collision event met speler>
Daarna moeten we het event een actie geven, zodat het level opnieuw begint.
Dat doen we door de actie "Restart Room" (Engels voor herstart de room) aan het event toe te voegen.
<img vijanden/restart_room.png 400 restart room>
Start nu het spel opnieuw en loop met de speler naar de vijand.

::question:: Wat gebeurt er als de speler tegen de vijand aanloopt?
::wrong:: De speler stopt bij de vijand, maar gaat niet terug naar het begin.
::wrong:: De speler gaat door de vijand heen.
::correct:: De speler gaat terug naar het begin.

::text::
De vijand is geen speler en moet uit zichzelf lopen.
Daarom moeten we hem van tevoren vertellen wat hij moet doen.
We willen dat de vijand naar beneden loopt.

Dit lijkt op de logica van de speler, maar nu voeren we de code uit zodra de vijand wordt gemaakt,
in plaats van wanneer de speler op een pijltjestoets drukt.
Dat doen we met het event "Create" (Engels voor aanmaken).
Het event Create wordt één keer uitgevoerd, zodra het object in het spel wordt geladen.
<img vijanden/create_create_event.png 400 create event toevoegen>

Ook moeten we de vijand een richting en een snelheid geven bij het Create-event.
Dit werkt op dezelfde manier als bij de speler.
We willen dat de vijand omlaag beweegt, met snelheid 2.
<img vijanden/snelheid_richting_vijand.png 300 richting omlaag en snelheid 2>

::question:: Wat gebeurt er met de vijand als je het spel start?
::wrong:: De vijand beweegt niet.
::correct:: De vijand loopt van het scherm af.

::text::
Nu beweegt de vijand alleen maar omlaag, maar we willen dat hij tussen twee punten heen en weer loopt.
Daarvoor maken we een nieuw object, het omdraai-object.
Maak eerst een sprite (bijvoorbeeld een pijl die terugwijst).
Maak daarna een object, op dezelfde manier als bij de vijand, en noem het "omdraai_object".
<img vijanden/omdraai_object.png 400 omdraai_object met sprite>

Nu hebben we een nieuw object, maar er is nog geen logica die ervoor zorgt dat de vijand tussen die twee punten loopt.
Daarom maken we nog een collision-event bij de vijand, maar nu met het omdraai-object in plaats van de speler.
<img vijanden/collision_event_vijand.png 300 collision event met omdraai_object>

Voeg in dit collision-event de actie "Reverse" (Engels voor omkeren) toe.
Hierdoor draait de vijand om zodra hij het omdraai-object aanraakt.
<img vijanden/collision_omdraai_object.png 300 reverse actie>

Zet nu omdraai-objecten direct boven en onder de vijand, zoals in het plaatje.
Hoe ver je de omdraai-objecten van de vijand af zet, bepaalt hoe ver de vijand heen en weer loopt.
<img vijanden/room_met_omdraai_object.png 300 omdraai-objecten boven en onder de vijand>

::question:: Start het spel. Wat doet de vijand?
::wrong:: De vijand loopt nog steeds van het scherm af.
::correct:: De vijand loopt heen en weer tussen de omdraai-objecten.
::wrong:: De vijand blijft stilstaan.
::wrong:: De vijand verdwijnt bij het omdraai-object.

::text::
Nu is het omdraai-object zichtbaar in het spel, en dat willen we liever niet.
Dat kunnen we oplossen met een nieuw event: "Draw" (Engels voor tekenen).
Kies bij het object "omdraai_object" voor "Add Event", dan "Draw" en nog een keer "Draw" (niet "Draw GUI").
Laat het event leeg.
<img vijanden/draw_event_omdraai.png 300 draw event toevoegen>
Door het Draw-event wordt het plaatje van het object niet meer getekend.
Het object bestaat nog steeds, dus de vijand draait nog steeds om als hij het omdraai-object aanraakt.

::question:: Waarom draait de vijand nog om, terwijl je het omdraai-object niet meer ziet?
::wrong:: Omdat het omdraai-object nog op het scherm staat.
::correct:: Omdat het object nog bestaat, het tekent zichzelf alleen niet meer.
::wrong:: Omdat de vijand het omdraai-object kan zien.
::wrong:: Omdat het omdraai-object een sprite is.

::question:: Gefeliciteerd! Je game heeft nu een vijand.

Je kan meer vijanden maken door de vijand vaker in de room te slepen.
Zet de omdraai-objecten dan ook goed neer bij elke vijand.
::check::

::correct:: Ik kan met de speler nu over het bord heen lopen.

::text::
We willen dat het bord alleen de tekst laat zien als de speler op staat. 
Maar we gaan eerst zorgen dat het bord altijd de tekst laat zien.

Tekst laten zien kan alleen in het "Draw" event. 
<img draw_event.png >
klick op "Add Event" (1) dan kies voor "Draw" (2) en dan weer "Draw" (3).

::question:: voer de code nu uit, wat zie je?
::correct:: Hé mijn bord is verdwenen.
::wrong:: Er lijkt niets veranderd.

::text:: Inderdaad! het bord is verdwenen. 
De code die in draw staat wordt ieder frame uitgevoerd om het object te tekenen.
Maar momenteel tekenen we helemaal niets! 

Als er geen draw event is tekent GameMaker de sprite, dat willen wij voor ons bord ook.
In GameMaker heet dat "Draw Self":
<img draw_self.png 400>
Sleep "Draw Self" naar het draw event.

::question:: Voer de code nu uit, wat zie je?
::correct:: Hé, mijn bord is terug!
::wrong:: Er lijkt niets veranderd.
::text::
we kunnen nu daadwerkelijk tekst toe voegen:
<img draw_value.png>

Sleep "Draw Value" onder "Draw Self" (1).
Verander de Caption naar "Welkom Bij mijn Spel" (2) 
Let op: De twee " aan het begin en eind zijn belangrijk hier.
We willen dat de positie van de text afhangt van de positie van het bord.
Dat kan je uitrekenen maar als je "Relative" aanklikt (3) maakt hij de positie automatisch relatief aan de positie van het bord.

Als laatste vullen we -20 in bij "y" (4).

::question:: Wat doet het invullen van -20 bij "y" in plaats van 0?
::wrong:: Het verplaats de text iets omlaag.
::correct:: Het verplaats de text iets omhoog.
::wrong:: Het verplaats de text iets naar links.
::wrong:: Het verplaats de text iets naar rechts.

::text::
We willen dat deze text alleen verschijnt als de speler op het bord staat.

In gamemaker kunnen we dat testen:
<img object_at_place.png 400>
Sleep "if Object at Place" (Engels voor is er een object op deze plaats) onder "Draw Self" (1)
Vervolgens kun je het object selecteren waar we op testen, bij ons de speler (2).
We willen relatief aan de positie van het bord testen, dus die mag je aanvinken (3).

Het "If" blok doet nu nog niets, hij gaat altijd door met tekenen.
